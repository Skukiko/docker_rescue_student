# R-01 — El backend no arranca: uvicorn no encuentra el módulo `app`

## Incidencia
El contenedor `backend` termina inmediatamente con `Exited (1)` tras `docker compose up --build -d`.

## Síntoma
`docker compose ps -a` (evidencias/01_ps.txt):
```
docker_rescue_student-backend-1    docker_rescue_student-backend    "uvicorn app:app --h…"   backend    9 seconds ago    Exited (1) 8 seconds ago
```

## Evidencia
Archivo: `evidencias/R-01_diagnostico.txt`
```
$ docker compose logs backend
backend-1  | ERROR:    Error loading ASGI app. Could not import module "app".

$ docker inspect --format '{{.Config.Cmd}}' docker_rescue_student-backend-1
[uvicorn app:app --host 0.0.0.0 --port 8000]

$ docker compose run --rm --entrypoint ls backend -la /app
-rw-rw-rw- 1 root root 1794 Nov 18 15:12 main.py
-rw-rw-rw- 1 root root   62 Nov 18 15:12 requirements.txt
```

## Causa raíz
El `CMD` de `backend/Dockerfile` indica a uvicorn que cargue `app:app` (módulo `app.py`, objeto `app`),
pero en la imagen solo se copia `main.py`, donde está definido `app = FastAPI(...)`. El módulo `app` no existe.

## Elemento modificado
`backend/Dockerfile` (instrucción `CMD`).

## Cambio aplicado
```diff
diff --git a/backend/Dockerfile b/backend/Dockerfile
index 1a54056..cc0c141 100644
--- a/backend/Dockerfile
+++ b/backend/Dockerfile
@@ -4,4 +4,4 @@ COPY requirements.txt .
 RUN pip install --no-cache-dir -r requirements.txt
 COPY main.py .
 EXPOSE 8000
-CMD ["uvicorn", "app:app", "--host", "0.0.0.0", "--port", "8000"]
+CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]
```

## Justificación
Cambio mínimo: se apunta al módulo real (`main`) sin renombrar archivos ni tocar el código de la API.
La forma `módulo:objeto` de uvicorn debe coincidir con el archivo copiado en `/app`.

## Verificación
Archivo: `evidencias/R-01_verificacion.txt`
```
$ docker inspect --format '{{.Config.Cmd}}' docker_rescue_student-backend-1
[uvicorn main:app --host 0.0.0.0 --port 8000]
$ docker compose logs backend
backend-1  |   File "/app/main.py", line 13, in <module>
backend-1  |     engine = create_engine(DATABASE_URL, pool_pre_ping=True)
...
backend-1  | ModuleNotFoundError: No module named 'psycopg2'
```
El error `Could not import module "app"` desaparece: uvicorn ahora importa `/app/main.py`.
El backend sigue en `Exited (1)`, pero por una causa distinta (driver de PostgreSQL ausente), tratada en **R-02**.

## Impacto si no se corrige
La API nunca arranca; el frontend no tiene backend y toda la aplicación queda inutilizable.
